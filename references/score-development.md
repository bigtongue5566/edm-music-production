# 從參考研究到配樂修訂

用於同一首配樂經多次小修仍缺少身份、張力或音色不合意的情況。電子配樂可借鏡電影配樂的主題與配器方法，不必改成管弦樂，也不要求影片才能使用。

## 先找出真正要改的維度

| 回饋 | 檢查 | 有效修改 |
| --- | --- | --- |
| 太慢、不夠緊湊 | BPM、細分、切分、休止、樂句長度；若有影片，再分辨資訊密度 | 改脈衝與鼓型、縮短呼應或增加事件；不一律加速整曲 |
| 一直重複、像背景迴圈 | 是否有核心材料；同一動機是否完全相同；聲部是否全程不退場 | 發展動機、換配器／音域、改鼓與低音互動、設計真正的撤出與回歸 |
| 鐘聲仍在、太金屬 | 所有有音高聲部、效果與殘響；起音、泛音、共振與尾音 | 替換問題音源或調整包絡／音域；不只改 preset 名稱或音量 |
| 平、沒有高潮 | 段落前後的聲部、音域、節奏和動態差異；母帶是否壓平對比 | 安排留白、聲部退出、節奏回歸與主題展開；不只增加總增益 |

單一作品的禁用音色、速度或情緒沿用該作品的要求，不能提升成其他作品的固定禁令。

## 研究參考曲的方式

優先查作曲家／製作人的第一手訪談、原始製作示範與官方資料，記錄來源及實際採用的方法。有聽音能力時，以段落時間碼記錄主題出現、配器、節奏、留白與動態；沒有直接聽音時，不宣稱已分析錄音的音色、BPM 或逐秒結構。

將「來源明確描述」「實際聽到」「本案推論」分開。可研究模組合成的不規則質地、反向聲音的起音形狀、主題在不同配器間的交接，但要自行寫動機與編曲。不要把特定電影的複雜速度變化當成所有短配樂都需要的功能。參考曲本身成功不表示照搬一項技法就能使本案成功。

把研究落成幾個可執行的選擇，例如「低音短動機作前景、長音作背景、高潮前撤鼓、回歸時改鼓型」。不只交付形容詞或著名曲名；使用者要求成品時，研究後繼續完成可播放音訊。

## 讓核心材料發展

1. 先完成一到兩小節的核心動機或節奏細胞，確認其節奏輪廓與聲部角色。旋律型作品可用少量音符建立記憶點；質地型作品可用可辨識的音色運動，無須強加旋律。
2. 保留能辨識的部分，再依和弦改音、改音域、縮短或延長節奏、改配器、安排問答。避免只把同一 MIDI loop 移調鋪滿所有段落，也不要用隨機換音代替發展。
3. 設計前景與背景：主題活動時減少競爭的琶音或效果，主題休止時由低音、鼓或和弦接力。使用者不要某種音色時，優先保留有用的音樂功能，換合適的樂器承擔。
4. 寫段落表，記錄時間、主題版本、活躍聲部、鼓型與進出 cue。短曲可用「建立—撤出—展開」形成對比，但不強制三段式或固定秒數。

## 真正實作段落起伏

「撤鼓」須在鼓軌移除擊打並處理尾音；「主題回歸」須有可追蹤的主題事件。整體乘上較小的增益只能稱作變小聲。核對 MIDI／automation 和實際分軌，不讓段落標籤與聲音不一致。

檢查活躍聲部時包含 note-off、release、延遲與混響；只有 note-on 數量不足以判定某段是否仍在發聲。短暫留白不必全聲部歸零，可讓一個主題尾音或背景長音維持連接。依 [continuity-and-articulation.md](continuity-and-articulation.md) 區分刻意空間與意外斷裂。

保留整曲的段落對比；不要逐段各自正規化到同一響度，再宣稱有動態發展。控制峰值時檢查限制器是否把撤出與回歸的差別壓平。

## 音色問題反覆出現時

不要只搜尋 bell 標籤。短促的明亮起音、非整數泛音、共振和長尾也可能讓 pluck、FM、鍵盤或效果聽起來像鐘。solo 各層並檢查效果 return，再在完整混音中比較；把問題聲部靜音可協助定位，但不是自動刪除所有旋律的理由。

簡單振盪器經多次調整仍無法達到目標時，改用成熟合成器、取樣樂器或可用的 DAW，而不是無限修改 sine/FM 係數。選音源前先確定角色、音域與 articulation。取樣樂器不等於真人現場演奏；來源與授權依 [composition-and-mix.md](composition-and-mix.md) 記錄。

## 可比較的交付

- 比較同一段、相近整體響度，包含問題音色及至少一次段落變化。有影片時沿用同一畫面；單獨作曲時不必建立影片。
- 提供清楚版本與實際修改清單，如「更換前景音源、間奏撤鼓、末段主題換音域」，避免只寫「更專業、更好聽」。保留可回退的基準版。
- 需要追查時輸出從相同時間零點開始、相同長度的分軌與 MIDI。交代分軌是在母帶處理之前或之後；非線性母帶處理下，分軌相加未必等於成品。
- 檢查完整母帶與最終編碼檔的片長、峰值、響度、接點和尾音。客觀檢查通過不等於使用者已認可音色或情緒；如實說明是否有實際試聽。
