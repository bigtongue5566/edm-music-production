# 協和與低張力的預設

預設以大／小三和弦、清楚的低音根音與平順的聲部移動組成完整樂句。用節奏、鼓型、音色、密度與動態建立不同曲風；不必靠七度／九度或半音張力來避免作品相似。

先做低張力版本，再疊聲部。主要重拍與延音以和弦音為主；較低音域減少密集排列，高音域也避免鋼琴／合成器多層尖銳 attack。三度、六度、五度與八度是常用的協和素材；三和弦轉位中的四度由根音與和聲脈絡判讀，不任意禁止。

沒有明確張力需求時，避開二度、七度、三全音、增減和弦、半音堆疊、7/9/11/13 延伸和弦，以及沒有解決的懸留／非和弦音。單音旋律可以有方向與休止，不能只為製造「高級感」塞進張力。換和弦時檢查先前的尾音與回聲是否疊到新音；共同音可延續，不相容的部分改寫或淡出。

**符合調性、符合單一和弦、同時發聲協和是不同檢查。** 逐一核對旋律、Pad、低音、和弦、尾音與效果的重疊。完整高音域 Dm7／Gm9 即使符合 D 小調，也不能當作低張力三和弦的替代；音域、力度、失諧及音色還會改變粗糙感。

範本預設 `music.harmonic_profile: "consonant"`。`harmonic_comfort.check_profile` 檢查跨聲部的同步音符與已追蹤的合成 release，發現 interval class 1、2、6、10、11 時停止作曲輸出，讓作者改寫音符、排列或重疊。它會檢查不同八度的二度／七度，不只檢查相鄰按鍵。

使用者明確指定需要張力、爵士延伸或實驗性和聲時，才選 `intentional-tension` 並記錄 `music.tension_intent`，安排張力的出現與解決。這個模式仍報告重疊音程；放寬協和設定不會跳過曲目的其他和聲檢查。

這是保守的符號檢查，不是聽感評分。取樣樂器真正的 release、效果尾音、失諧、泛音、音量及聲部遮蔽，仍要在實際渲染音訊中檢查。和弦協和不能保證音色舒服；必要時用相同音色比較三和弦／延伸和弦，再用相同和弦比較音色，避免同時改很多項卻斷言只有一個原因。
